# LifeLine-AI
Emergency + Help Finder Platform
🌍 LifeLine AI

🚨 Emergency + Help Finder Platform

LifeLine AI is a smart emergency assistant that helps users:

- Send SOS alerts 📍
- Find nearby hospitals 🏥
- Get AI guidance 🤖
- Access help even offline 🌐

🛠 Built With

- Flutter
- Firebase
- Google Maps API
- AI Chat Integration

🎯 Features

- One-tap SOS
- Live location sharing
- AI emergency assistant
- Multi-language support

🚀 Future Scope

- Government API integration
- Disaster alerts
- Community help network
